## Dataset protocol

**AV-WIDE** is the first target. The source README and MATLAB plotting scripts establish `I2` RGB input and `G.V` XY / `G.A` adjacency; MATLAB pixel centers are converted to zero-based XY once. Original dense graph paths are contracted through degree-2 vertices; component and cycle counts must be preserved. Simple-graph representations retain closed/parallel curves using explicit degree-2 anchors. No rasterization, crossing reconnection, spur pruning or distance-based node merging occurs.

The fixed split is training images 01, 03–06, 08–19 (17), validation 02, 20–24 (6), reserved test 25–30 (6). This retains the old development roles of 01/02. Patient/eye IDs are absent in the supplied description and graph metadata: **image-disjoint only; no patient independence claim**. Test inspection is limited to MAT variable headers. Test arrays, crops and predictions are not loaded/generated. Image 07 is excluded because `G.A[1268,1268]` is a self-loop without an associated nonzero path; no repair or substitution is made. Three nodes in image 10 and two in image 12 lie outside source extents and are handled by the same geometric clipping used for every image.

All fixed 128² spatial grid crops are kept, including empty targets. Last row/column shift inward to cover image edges, causing within-image overlap there. No crop crosses split boundaries. Dense segments are exactly clipped to `[0,127]²`, including outside/outside and reentering paths. Artificial boundary anchors are supervised and evaluated explicitly. This is a **crop graph extraction** experiment, not full-image stitching. Crops near the optic disc and ambiguous crossings are included with the supplied connectivity; scores measure agreement with those annotations, not newly validated biological connectivity.

There are **1,385 training and 506 validation tiles**. Training contracted-node quantiles: median13, p95=41, p99=58, max76. Capacity is **96 queries**, the training maximum plus 25% rounded to eight; every validation tile fits without discarded nodes. Spacing is unknown: use **pixels**, never millimeters. ## Controlled training and stopping rules

B0 and A-xyz both use the original-width **ResNet101, width 512, 3 encoder + 3 decoder layers, 4 scales, 5 relation tokens**, all backbone parameters trainable. No pretrained download or checkpoint initialization. Node softmax focal γ2 with equal class weights, existing Hungarian costs2/5, matched-edge CE, ratio upsampling0.15±0.02, no unmatched-edge mining. K8 cubic geometry uses detached `graph_only` gradients. Only A-xyz enables the existing zero-initialized coordinate-only nine-sample image refiner, radius4 px. Its initialization is RNG-contained; shared parameter tensors and initial outputs must be exactly equal.

Gate job: `1653554`, one H100, 25-minute bound. Required checks: eight existing CPU regressions, syntax, full-model 128² shared-initialization/output parity, finite total backward, refiner gradient and isolated spline backward. Then a fixed **1,200 full-model optimizer updates** on two easy training tiles with dropout disabled via evaluation mode; require micro node F1≥0.9 and edge F1≥0.8 at 2 px. This gate checkpoint is **never** used to initialize either arm. Failure stops the pilot without extending memorization. Successful two-tile fitting is still not held-out evidence.

After that gate, benchmark the existing PyTorch `grid_sample` 2D deformable-attention core and actual batch 4 training in each arm (3 warmup +12 measured full updates). Select one common budget from measured worst-arm throughput: at most6,000 updates, at most40 training passes and approximately1,800 seconds of training per arm, rounded down to100 updates. Require at least1,000 updates or stop. Evaluation time is additional and bounded by the Slurm walltime. Budget and timing are written to `gates.json` **before** either training arm launches.

Both arms restart from seed364505; hash all shared initial weights. They use the same saved shuffled exposure schedule, D4 rotation/flip draws by exposure, batch 4, dropout0.1, AdamW LR2e-4 / backbone2e-5, weight decay1e-4, gradient clipping0.1,100-update linear warmup followed by cosine decay to10% of base LR. Per-update CPU/GPU RNG seeds keep dropout and relation sampling aligned. Different predictions can change Hungarian assignments; matcher policy remains identical. Nonfinite loss/gradients stop a run. No hyperparameter sweep, denoising, new matcher, proposals or adaptive budget extension.

## Target-fit defect found during final QC; one controlled correction

The shared training-loss spike at update 4500 was traced to `wide13_x128_y256`, branch7: its original16 polyline vertices leave a long unsampled tail in arc coordinates. The cubic least-squares design is nearly unconstrained in one basis span, producing a control coordinate of−56,890 px inside a128² crop. The original pilot remains archived and **must not support a reliable geometry conclusion**. Detached spline gradients do not make this harmless: global gradient clipping includes the spline head and can affect the shared detector update scale.

The narrow correction samples the **same piecewise-linear guide uniformly at 64 arc-length positions** before fitting K8 controls. Nodes, adjacency, crop boundaries, endpoints, dense reference paths, metrics, units, split membership and data exposure remain exactly unchanged. This explicitly changes only the numerical geometry target approximation, to an arc-length-weighted fit. A real-branch regression replays the frozen original function and fails, while the corrected function and eight existing native2D regressions must pass. Every development target is refit and checked; test arrays remain unopened.
