## Controlled protocol

Use the existing full native 2D ResNet101/512D RelationFormer (3 encoder/3 decoder layers, four feature levels, five relation tokens), Hungarian matching, modern node softmax focal loss gamma 2, matched-edge CE positive/negative ratio 0.15 and K8 splines with detached `graph_only` gradients. A-xyz adds only the existing image-conditioned coordinate refinement. No denoising, new matcher, proposals or unrelated architecture changes.

For each ready vessel cohort (AV-WIDE, separately calibrated REAVER diaphragm60x, OCTA-Synth), run B0 and A-xyz from scratch for **100 exact epochs**. Separately pretrain one B0 for **50 mixed epochs on plants plus that target's training split**, then initialize B0 and A-xyz from that target-specific final checkpoint and finetune for **100 vessel-only epochs**. Both variants receive the entire shared checkpoint, including the spline head and query embeddings; A-xyz starts with zero coordinate residuals. Finetuning resets the optimizer and schedule, with no plant replay. No vascular datasets are pooled together. Validation/test images never enter pretraining.

Seed 364505; D4 augmentations and shuffled complete passes identical within each paired vessel comparison. Keep final partial batches. Vessel-only training has no oversampling; mixed pretraining uses the established replacement sampler described above. Target batch size4; mixed-pretraining batch32, subject to the measured GPU gate. AdamW learning rates2e-4 (core) /2e-5 (backbone), weight decay1e-4, clipping0.1,100-update warmup followed by cosine decay to10% over each new complete schedule. Shared query capacity is96, derived from contracted **training** node counts and checked against validation without using validation to select capacity. All query slots transfer unchanged.

Mixed-pretraining geometry uses **image pixels for both domains**. On REAVER samples, divide the calibrated metric by its measured isotropic pixel pitch on a copied target; normalized nodes, controls, paths and original cached micron targets remain unchanged. Pretraining validation uses only the target validation cohort, in pixels; no pooled plant/vessel validation metric is selected or reported. REAVER vessel-only fine-tuning and final physical metrics restore the original micron convention. The spline head transfers as initialization across that unit change; no physical calibration is invented for plants. Pixel-stage and micron-stage F1 curves are plotted separately.

Before training: targeted CPU tests; full-model initialization parity, coordinate-refiner gradient and detached-spline routing checks; a fixed 1,200-update full-model two-crop overfit per cohort (node F1 >=0.9 and edge F1 >=0.8 at two native distance units); strict trained B0 to A-xyz transfer parity; production-batch real-image forward/loss/backward throughput and memory benchmark. Gate weights are discarded. Training jobs are bounded at 14 hours and must fit the benchmark-derived budget. Stop at the declared epoch count or on nonfinite values/errors. No automatic extensions, threshold sweeps or hyperparameter searches.

Primary results use the final fixed-epoch checkpoint on complete validation populations. Every five epochs, evaluate the same fixed source-image/crop subset; select secondary checkpoints by its edge F1 at two native distance units, latest trained tie. Initialization is never eligible. Preserve node/edge AP/AR, raw and filtered recall, conditional relations, duplicates, components/cycles, and same-predicted-graph Branch/Curve F1 for K8 versus straight chords. Pixel and micron metrics remain separate. Plant graphs have sparse supplied polyline guides, so plant validation does not claim independently traced dense-curve supervision. Test arrays and predictions remain untouched.
