Dataset Summary:Each image folder contains 36 images. For each image:The first channel (red) is the segmented image with values of 0 or 255 (false or true).The second channel (green) is the skeleton image with values of 0 or 255 (false or true). The third channel (blue) is empty except for the Manual images where the third channel contains the original raw image.Subfolders_Original_Images: contains raw input images.AngioQuant_Auto: contains output images from automated analysis in AngioQuant.AngioTool_Auto: contains output images from automated analysis in AngioTool.ImageJ_Auto: contains output images from automated analysis in ImageJ.ImageJ_Manual: contains output images from manual analysis in ImageJ.RAVE_Auto: contains output images from automated analysis in RAVE.REAVER_Auto: contains output images from automated analysis in REAVER.Image Metadata and Output dataEach image folder has a .mat file called “Results.mat” containing the results of analysis in the form of the following variables all of which are 1x36 arrays (one entry for each image) unless specified otherwise:branchpoint_RC: A 1x36 struct containing the row-column values for each branchpoint in the ith image (when organized in alphabetic order which is the order given everywhere else); Effectively the same as “BranchpointsByName.mat”mean_diameter: The mean diameter of vessels in the imagenum_branchpts: The number of branchpoints in the imagethreshold_false_neg: The number of false negative pixels – a pixel is a false negative if the program has it as “false” and the manual image has the pixel as “true”threshold_false_pos: The number of false positive pixels – a pixel is a false positive if the program has it as “true” and the manual image has the pixel as “false”threshold_true_neg: The number of true negative pixels – a pixel is a true negative if the program has it as “false” and the manual image has the pixel as “false”threshold_true_pos: The number of true positive pixels – a pixel is a false positive if the program has it as “true” and the manual image has the pixel as “true”umppix: The length of the edge of one pixel in micrometersvessel_area: The number of “true” pixels in the segmented imagevessel_length: The number of “true” pixels in the skeleton imageDataset Output DataThe file “image_quantification.csv” in the base folder contains the aggregated results from each image folder. Each row contains the results for a given (Program, Image) pair. The columns are described below:Program: Designates the program used to calculate the data for that rowTissue_Type: Gives the tissue type for the imageImage_Name: Gives the specific name of the given imageVessel_Length: The number of “true” pixels in the skeleton imageVessel_Area: The number of “true” pixels in the segmented imageMean_Diameter: The mean diameter of vessels in the imageNum_Branchpoints: The number of branchpoints in the imageSensitivity: (Number of True Positive pixels) / (Number of True Positive pixels + Number of False Negative pixels)Specificity: (Number of True Negative pixels) / (Number of True Negative pixels + Number of False Positive pixels)Accuracy: (Number of True Positive pixels + Number of True Negative pixels) / (Total number of pixels)umppix: The length of the edge of one pixel in micrometerspix_dim: The edge length in pixels of the square imageReferences ADDIN ZOTERO_BIBL {"uncited":[],"omitted":[],"custom":[]} CSL_BIBLIOGRAPHY 1.Niemisto, A., Dunmire, V., Yli-Harja, O., Wei Zhang & Shmulevich, I.
